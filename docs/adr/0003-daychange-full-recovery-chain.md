# 跨天弹窗采用全自动恢复链而非识别后安全停止

00:00 后首局触发的「日付が変わりました。」强制弹窗唯一出口是「×タイトルヘ」回标题页（正文区/右上×実機不可关），夜间挂机必遇且守卫点击落弹窗外会死循环。决定实现全自动恢复链（管线识别 → 点×タイトルヘ → 段退出 → StartUp 重拉起 → 中断局续跑），而非「识别+安全停止」——夜间挂机零介入是 HIF 管线的核心目标，且中断局无缝恢复已在 2026-08-23 轮 12 実証。代价：段驱动层（debug/hif_run.py）必须接管标题页重拉与续局判定，管线与驱动的职责边界跨出单段 Produce。

## Considered Options

- 识别+安全停止（白天人工恢复）：实现最简，夜间挂机仍中断——被拒
- 识别+重拉新局（放弃中断局）：复杂度居中，作废半局进度——被拒（恢复链已証可行）
- 全自动恢复链：选定（2026-08-23 修复计划用户裁决）
