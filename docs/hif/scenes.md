# HIF 本战场景卡（设计真源）

本文件是 HIF 培育管线的人读设计真源：从 `ProduceEntryHIF` 入口到 Round1 到达为止的全部游戏场景，每场景一张卡。执行真源是 `assets/resource/base/pipeline/ProduceHIF.json`；两处冲突时以实机取证结论为准并同步两边。

维护规则（2026-08-14 设计评审锁定）：

1. **模板优先**：静态 UI/图标/按钮一律 TemplateMatch；OCR 仅用于①页面标题/提示行文案锚（必须实机取证，禁止推测）②体力/回合等数字。已实机验证的 OCR 锚不回退改造。
2. **文档+后验断言**：点击节点 `next` 指向预期场景 Flag，未到达经节点 `timeout` 超时走 `on_error → ProduceHIFUnknownStop` 安全停止；不在 `next` 尾部挂 DirectHit 兜底。
3. **转移标注**：`→` 确定转移；`→{A|B}` 概率转移。本战日程为固定脚本，概率仅 3 类：Day3 玩家二选一、公開レッスン SP 与否当日决定、変卡候选内容随机。
4. **状态标注**：`[已验证]` 实机命中过；`[未验证]` 管线已接但无实机证据；`[待取证]` 文案/坐标/存在性存疑；`[缺口]` 无记录需实机补录。

坐标基准：MuMu 720×1280 竖屏，日服 Ver 3.2.3。截图原始路径见 `finals-daily-log.md` 各日「观察来源」；日志原图不入库，关键锚小图裁至 `docs/hif/screenshots/`。
