# HIF 实机观察条目表

本页将 [`finals-daily-log.md`](finals-daily-log.md) 的时序截图观察拆成可复用的原子条目。原始日志仍是截图、操作顺序和完整上下文的唯一来源；本页不替代它，也不保存截图副本。

适用环境：MuMu 模拟器 12、ADB、日文原版、莉波 `感性·好调` 当前样本。整理日期：`2026-07-18`。

## 升级规则

- 单次观察只能用于只读识别、模型字段或测试待办，默认不能授权点击；
- 同一结论经重复实测或游戏内说明核对后，可提升到 [`summary.md`](summary.md) 的机制条目、[`testing.md`](testing.md) 的测试契约或当前工程决策；
- 候选不完整、目标不唯一、截图方向不符合契约或后态未知时，仍进入安全停止。
