# ADR-20260718：文档库直接写入

状态：有效。日期：`2026-07-18`。

## 决定

完成开发、Pipeline 修改、实机测试或机制研究的代理，直接维护本任务范围内的权威文档，不只在交付中提出建议或等待额外确认。

## 边界

- 可复核机制事实写入 `docs/game-knowledge/`；HIF 核心机制写入 `docs/game-knowledge/hif.md`。
- 当前有效工程取舍写入 `docs/decisions/`；被替代项归档。
- 可复用经验写入 `docs/experience/` 或对应专项复盘。
- 单次观察、截图和 Journal 先进入观察/证据层，不能据此授权不可逆点击。
- 无长期增量时不创建占位文档，交付中明确“无文档增量”。

## 例外与复核

结论超出用户任务范围、来源冲突且无法安全归类，或写入需要新的外部授权时，代理应请求方向。Hook 只检查是否完成文档影响声明，不替代内容判断。
