# 开发与测试经验

记录可复用的实现、识别和实机测试教训，例如页面锚点陷阱、验证缺口、环境差异或失败复盘。

经验必须标明适用场景和证据链接；它不是游戏机制事实，不能单独授权自动点击。若经验经来源核对或重复实机验证后成为事实，再同步到知识库。

HIF 已有的专项复盘继续保留在 `docs/hif/`，例如 `day2-lesson-retrospective.md`；这里只存跨场景或新建分类的经验入口。
