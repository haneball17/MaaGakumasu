## 6. 关键机制发现（待补入 mechanics.md）

1. **SKIP=空过 1 回合**（A，2026-08-20 用户実機实测确认；首版曾误判 stage 级）：单击 SKIP 只消耗当前回合，不放弃 stage。首次実機观测点 SKIP 后 Vi→Da、回合分数倍率变化（3168%→3956%）、体力 31→33（+2）、手牌全换，当时误读为「跳过整个 stage」——实为该 stage 残りターン恰剩 1，SKIP 空过末回合后 stage 自然切换，上述现象均为 stage 切换的伴随效果。与 roundsim 的 1 回合建模一致，`GarakutaRinamiStrategy` 的 SKIP 动作无需禁用（典型使用场景：无牌可出/出牌带来负面效果）。
2. **stage 结构**：Round1 由多个不同タイプ的試験串联（每 stage 独立残りターン/手牌/体力小幅回复），体力跨 stage 保持。C（仅观测到 1 次切换）
3. **选中即预览**：选中态体力栏显示扣费后值——判断「卡费是否超过当前体力」可直接读选中预览，也可先读常规态体力-卡费计算。B
4. **好調状态过期即消失**（A 置信度，2026-08-20 連拍+用户指认验证）：打出「好調 Nターン」卡后**左側効果区顶部**出现天蓝色菱形好調图标（[24,244,38,35]，内部力量手势剪影），图标**不显示层数**，右侧「Nターン」为剩余持续回合；耗尽后图标整个消失（非置灰）。「好調 Nターン」的 N 是持续时间而非叠层（实测「鳴り止まない拍手」好調2ターン打出后图标右侧 2ターン 递减）——层数语义与显示见 §7 修正记录。
5. **出牌后演出自动推进**（B）：出牌确认 → 卡效果演出（SKIP 隐藏、手牌收起，实测 1-3.5s）→ 対手回合（SKIP 仍隐藏）→ 自动回到自身待输入（SKIP 复现+手牌重发）；全程「残りターン」标题**常驻**，演出期间 `Round1Flag` 持续命中——单靠该锚无法区分演出态与待输入态。
