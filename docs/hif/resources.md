# HIF 资源与模板清单

本页只负责识别资源、模板、ROI 和采集清单。

不再承载 HIF 主线机制结论。

## 1. 当前主线环境

当前 HIF 资源主线固定为：

- `MuMu 模拟器 12`
- `Adb`
- 日文原版
- 常规页面原始竖屏 `720x1280 (240DPI)`

DMM 冻结记录单独看：

- [`dmm-baseline.md`](dmm-baseline.md)

### 截图方向契约

当前实测结论（2026-07-18，待后续原始帧复核）：

- 除 Live 外，HIF 页面均按原始竖屏 `720x1280` 采集、标注 ROI 与执行；
- 只有 `Round2` 结束后播放的 Live 视频会切换为横屏 `1280x720`；
- Live 使用独立页面锚点与坐标合同，不复用竖屏 ROI，当前仅允许观察；其他横屏帧一律安全停止。
