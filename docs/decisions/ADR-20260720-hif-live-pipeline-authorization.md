# ADR-20260720：HIF 实机管线验证须显式授权

状态：有效。日期：`2026-07-20`。

## 决定

除非用户在当前任务中明确要求，代理不得启动 HIF 实机管线验证，包括连接设备、启动 `tools/hif_live_runner.py`、提交 Maa Pipeline 任务或发送任何控制器输入；即使任务配置为零输入观察也不例外。

离线 JSON、截图、ROI、单元测试和静态契约检查不属于实机管线验证，可按任务范围执行。

## 影响

- `assets/resource/base/pipeline/test/TEST_HIF_2.json` 中的单步入口只供用户显式要求的手动实机测试使用；代理默认不运行。
- HIF 的截图、Journal 和日志只能在已获授权的实机运行后采集；未获授权时以现有证据完成离线设计与安全审查。
- 一次明确授权仅覆盖用户指定的任务和输入范围，不自动授权后续页面、额外点击或连续运行。

## 复核

用户在当前任务明确提出“实机验证”“运行 HIF 测试管线”或等效指令时，才可在其指定范围内执行；其余情况下保持离线。
