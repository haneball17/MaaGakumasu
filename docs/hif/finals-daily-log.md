### 对离线模拟器的建模含义

- 本战准备阶段第一天不是单一固定行动，而是 3 个属性授业候选。
- 当前可先建模为 `finals_prepare` 阶段、剩余 `6日`、候选集合为 3 个 `lesson`，其中左侧粉色属性 `lesson` 会进入一个 3 选 1 的事件选项层。
- 候选应至少带有属性标签：
  - `mic_lesson` 或后续统一命名的粉色属性标签
  - `shoe_lesson` 或后续统一命名的蓝色属性标签
  - `expression_lesson` 或后续统一命名的橙色属性标签
- 左侧粉色属性 `授業` 的第一个事件选项可先建模为：
  - `stamina_delta = -5`
  - `attribute_delta.mic = +180`
  - `effect_tags = ["good_condition", "skill_select_change"]`
  - `requires_skill_selection = true`
- `skill_select_change` 不是单步收益，而是两阶段卡牌转换流程：
  - 阶段 1：从 3 张候选技能卡中选择目标卡 A，可 `再抽選`，当前观察到 `あと3回`。
  - 阶段 2：进入牌库选择一张已有卡 B，将 B 转换为 A。
- 离线模拟器里应把这个效果拆成：
  - `generated_card_candidates`
  - `reroll_count`
  - `deck_replace_candidates`
  - `selected_new_card`
  - `selected_replaced_card`
- 当前已能为 `generated_card_candidates` 记录至少两个详情样本：
  - `立ち位置チェック`：集中消耗 `3`，`元気+15`，`パラメータ+30（好調効果を2倍適用）`，`元気増加無効2ターン`，`レッスン中1回`。
  - `エキサイト`：`パラメータ+6`，`絶好調3ターン`，`レッスン中1回`。
- 重抽后新增目标卡样本：
  - `始まりの合図`：`好調5ターン`，`レッスン中1回`。
- 牌库选择卡 B 阶段需要把可见牌库建模为可滚动列表，不能只读取首屏卡牌。
- 本次完整转换样本可记录为：
  - `selected_new_card = "始まりの合図"`
  - `selected_replaced_card = "大胆不敵"`
  - `conversion_result = "大胆不敵 -> 始まりの合図"`
  - `confirmation_text = "大胆不敵を始まりの合図にチェンジしました"`
- 中、右两个底部 `授業` 候选，以及左侧 `授業` 的第二、第三事件选项收益仍应标记为 `needs_result_capture`。
- 该截图可作为 `route_candidates.json` 中本战准备第一天候选池的第一条实机证据。
