## 4. 当前工程归纳

这部分不是外部来源，而是开发侧对现有资料的统一抽象。

### 4.1 已落入当前代码 / 模拟器的结论

- `HIFEvaluationConfig`
  - 选拔属性结构
  - 本战权重结构
  - 星星主来源结构
- `SelectionSnapshot`
  - 选拔结束摘要
- `SelectionMemoryProfile`
  - 本战输入摘要
- `selection_evaluation / finals_evaluation / star_evaluation`
  - 当前 CLI 报表字段

### 4.2 仍是工程假设的内容

- 记忆质量、牌组质量的代理评分方式
- 当前样本日程中的候选池
- 当前 `beam search` 的深度和宽度
- 当前“低 / 达标 / 高”星星区间划分
- `3200` 上限环境对 simulator 评分阈值应如何落地

这些都不能当作机制事实，只能视为当前开发实现。

## 5. 当前仍需实机验证的关键项

- HIF 固定日程中的真实候选集合
- `相談` 内部购买 / 强化 / 删除的实际候选规律
- 本战前支援事件的触发时点和频率
- 星星对试验 / 本战分数的实际影响幅度
- 各类收益是否存在版本更新后的变化
- `HIFボーナス` 的完整参数表
- `3200` 上限下不同路线收益差的实机确认

## 6. 使用建议

后续开发时：

- 需要确认“机制是否可靠”时，先看本页
- 需要直接理解 HIF 总体结论时，看 `summary.md`
- 需要把机制变成评分字段时，看 `evaluation.md`
- 需要把不确定性接入模拟器时，看 `randomness.md`
