# HIF 资源与模板清单

本页只负责识别资源、模板、ROI 和采集清单。

不再承载 HIF 主线机制结论。

## 1. 当前主线环境

当前 HIF 资源主线固定为：

- `MuMu 模拟器 12`
- `Adb`
- 日文原版
- `1280x720 (240DPI)`

DMM 冻结记录单独看：
