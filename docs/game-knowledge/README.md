# 游戏机制知识库

这里记录可复核的《学园偶像大师》机制事实。按剧本或跨剧本范围创建条目；没有内容时不要预建空目录。

## 权威入口

- HIF：[`hif.md`](hif.md) 是核心机制条目的权威正文；详细解释、证据与工程上下文见 [`../hif/README.md`](../hif/README.md)。
- 跨剧本机制：在 `common/` 首次有内容时创建。
- 初、NIA 等剧本：在各剧本首次有内容时创建同名目录和 README。
- 程序需要消费的卡牌、饮料、P-item 或结构化观察，放在 `assets/data/`；本文只解释机制和链接来源。

上述页面中标为工程假设、单次观察或社区经验的内容仍是待验证材料，不能因为被汇总到知识库而提升可信度。

## 条目要求

每条结论至少包含：

- 结论与适用范围/游戏版本；
- 可信度：官方或游戏内确认、实机重复验证、单次观察、社区经验；
- 来源或证据路径；
- 最后验证日期。

单次观察和社区经验必须标为“待验证”，不得作为自动点击或不可逆操作的唯一依据。原始 `debug/` 证据可供当轮复查；需要长期依赖时，应补充可提交的结构化观察或稳定外部来源。
