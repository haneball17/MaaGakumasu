# HIF MVP

本页只负责 HIF MVP 范围与验收口径。

## 1. MVP 目标

当前 HIF MVP 的成功标准仍然是：

- 从 HIF 入口开始
- 完成一次完整 HIF 育成
- 到达结算页
- 正常退出或回到可控状态

## 2. 当前主线环境

- `MuMu 模拟器 12`
- `Adb`
- 日文原版
- `1280x720 (240DPI)`

DMM 当前不是 HIF MVP 的主验收平台。

## 3. MVP 包含什么

- HIF 入口识别
- 选拔阶段推进
- 本战阶段推进
- `Round1 / Interval / Round2`
- 失败页停止
- 结算页回收

## 4. MVP 不包含什么

- 全局决策引擎
- 高评价最优化
- 完整出牌模拟
- 多角色泛化

## 5. 当前与文档其他部分的关系

- 机制背景看：`summary.md`
- 评价体系看：`evaluation.md`
- 随机性看：`randomness.md`
- 实现边界看：`architecture.md`

## 6. 一句话总结

HIF MVP 关注的是：

> 先把流程闭环打通，而不是先把高评价和全局最优一起做完。
