# HIF 高评价目标

本页只讨论 HIF 的高评价方向，不承担当前主线开发说明。

当前第一优先级仍然不是高评价最优化，而是：

- 机制稳定
- 文档稳定
- CLI 模拟稳定
- 后续接回自动化

## 1. 当前定位

高评价文档用于回答：

- HIF 最终往哪个目标优化
- 哪些变量会在高评价阶段变得特别重要
- 哪些内容必须等实机验证后再加权

## 2. 当前推荐高评价目标

当前更合适的目标是：

- 先以 `S4+` 为第一优先级

而不是一开始就把：

- 理论极限
- 单次最优样本

作为主目标。

## 3. 当前已知的高评价重要变量

当前资料支持这些变量在高评价阶段很重要：

- 星星
- `SelectionMemoryProfile`
- 牌组厚度
- 核心技能覆盖率
- `Interval` P 点预算
- HIF P 道具协同
- 支援卡事件时点

## 4. 与当前主线的边界

这部分暂时不要反向污染：

- `mvp.md`
- 当前 `P0` 决策
- 当前实机接入路径

也就是说，高评价阶段需要的复杂策略，不应成为当前 HIF 可用性的阻塞项。

## 5. 对后续算法的要求

如果要进入高评价阶段，至少要补：

- 真实候选池
- 更强随机性建模
- 更完整奖励池
- 更强搜索器
- 更可信的星星 / 记忆质量 / 本战收益模型

## 6. 一句话总结

高评价目标不是当前 HIF 主线的起点，而是：

> 在机制、评价、随机性和样本模拟都稳定后，再逐步推进的第二阶段目标。
